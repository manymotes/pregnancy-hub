# PregnancyHub

Comprehensive pregnancy information website with week-by-week guides, nutrition advice, and expert tips for expectant mothers.

## Features

- 📅 Week-by-week pregnancy guides (weeks 1-40)
- 🤰 Trimester-specific information
- 🥗 Nutrition and diet guidance
- 💭 Symptom management
- 👶 Baby development tracking
- 🏥 Prenatal care information
- 🧘 Exercise and wellness tips
- 🏩 Labor and delivery preparation
- 🤱 Postpartum care guidance

## Technology Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Static export (SSG)
- **Analytics**: Google Analytics 4
- **Monetization**: Google AdSense

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Site Structure

- `/week-by-week` - Week-by-week pregnancy guides
- `/first-trimester`, `/second-trimester`, `/third-trimester` - Trimester guides
- `/nutrition` - Nutrition and diet information
- `/symptoms` - Common pregnancy symptoms
- `/baby-development` - Baby development information
- `/prenatal-care` - Prenatal care guides
- `/exercise` - Safe exercises during pregnancy
- `/labor-delivery` - Labor and delivery information
- `/postpartum` - Postpartum care guides

## Configuration

Update the following in `lib/config.ts`:
- Google Analytics ID
- Google AdSense Client ID (already configured)

## Content Strategy

The site follows a programmatic SEO approach targeting high-volume pregnancy-related searches:
- 40 week-by-week guides
- Trimester-specific content
- Topic-based guides (nutrition, symptoms, etc.)
- Long-tail keyword targeting
